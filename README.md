# spotadaptative

Site statique (`index.html` + `icon.png`) publié avec GitHub Pages.

## Publication

Settings › Pages › Source : branche `main`, dossier `/ (root)`.
L'adresse est `https://<compte>.github.io/<dépôt>/`.

## Brancher Spotify

- Dans Réglages de l'application (maintenir le bouton 2 s), copier l'**adresse de redirection** affichée.
- La déclarer telle quelle (caractère pour caractère) dans le tableau de bord Spotify, avec *Web API* et *Web Playback SDK* cochés.
- Coller le Client ID dans l'application, puis « Se connecter à Spotify ».

Sans Client ID, l'application tourne en mode démo.
